# 不买服务器，怎么让别人试用

> 前提：你的电脑就是服务器。**你的电脑关了、休眠了、断网了，别人就访问不了。**
>
> 适合场景：内部小范围试用、演示给领导看、备案下来之前的临时试用。
> 不适合：审核员分散在全国各企业现场**长期**使用（那必须上云）。

---

## ★ 你的情况：审核员不在同一网络 → 直接看方案 B

**已经给你装好了，一个命令就能用，不用注册账号。**

```
第1步  双击  打开评估工具.cmd          （启动服务，窗口保持开着）
第 2 步  双击  生成公网访问地址.cmd     （等 10 秒，出现一个 https:// 地址）
第 3 步  把屏幕上那个 https 地址发给审核员
```

**实测结果**（我在这台机器上跑通了）：

| 检查 | 结果 |
|---|---|
| 连通性预检 | DNS / UDP / TCP / API **全部 PASS** |
| 启动成功率 | 加证书池后**连续 4 次全部成功**，零失败 |
| 隧道就绪耗时 | **约 2 秒** |
| 公网地址返回 | `{"ok":true,"db":"up"}` |
| 首页 HTTP 状态 | **200**，响应 1.2 秒 |
| 地址自动复制 | 验证通过，剪贴板里就是那个网址 |

⚠️ **两条铁律**：
1. **窗口不能关**。关掉窗口 = 公网地址立刻失效。
2. **URL 每次重启都变**（随机子域名），所以别提前把地址发给审核员，要用的时候现生成。

## 方案 B · 公网穿透（你的主方案）

### 为什么用 Cloudflare Tunnel

| 优点 | 说明 |
|---|---|
| **不用注册账号** | 别的穿透工具（cpolar/natapp）都要注册再拿 token |
| **不用花钱** | 免费、无流量限制 |
| **自带 HTTPS** | 自动证书，不用自己配|
| **不用备案** | 走Cloudflare 的全球边缘，不是国内服务器 |
| **一条命令** | 不需要配置文件 |

**代价**：URL 随机且每次重启变；**没有在线率保证**（Cloudflare 官方声明免账号隧道不作 SLA 承诺）。

### 完整操作

```
第 1 步  双击  打开评估工具.cmd
         等窗口显示「服务已启动」，窗口保持开着

第 2 步  双击  生成公网访问地址.cmd
         等约 15 秒，屏幕会出现一个**大框**：
         ==============================================================
              PUBLIC URL IS READY  (copied to clipboard)
              https://xxxx-xxxx-xxxx.trycloudflare.com
         ==============================================================

         地址已自动复制到剪贴板，直接 Ctrl+V 发出去就行

第 3 步  把这个地址发给审核员
```

> ★ **为什么网址要放大框显示**：cloudflared 启动时会刷一屏预检日志
> （DNS / UDP / TCP / API 全 PASS），网址被顶到上面去了，要往上翻才看得见。
> 所以我另写了个脚本从日志里把网址抓出来，单独大框显示 + 自动复制。

### 如果提示「等不到公网地址」

先看目录里的 `tunnel.log`，脚本会给出具体原因：

| 提示 | 原因 | 怎么办 |
|---|---|---|
| `TLS certificate check failed` | 本机证书库缺 Cloudflare 信任链 | 脚本已指定 `ca-bundle.crt`，并内置 3 次自动重试，一般直接就好了 |
| `Could not reach Cloudflare` | 本地网络不通 | 检查网络，断了 WiFi 或开着代理时容易出现 |

**实测数据**：加证书池后连续 4 次启动全部成功；最终端到端复测 ——隧道 2 秒就绪、网址大框正常弹出、地址自动进剪贴板、公网健康接口返回 `{"ok":true,"db":"up"}`、首页 200（1.2 秒）、关窗口后旧地址返回 530 确认失效。

### 换机怎么办

需要两个文件，跟着文件夹一起拷：

| 文件 | 说明 |
|---|---|
| `cloudflared.exe` | 53MB，Cloudflare 官方下载 |
| `ca-bundle.crt` | 224KB，从 Git 自带的证书包复制 |

> ★ **`ca-bundle.crt` 别删**。这台机器的 Windows 根证书库只有 46 个证书、
> 一个 Google 都没有，Go 程序（cloudflared 用 Go 写）不自带证书包，
> 会间歇性报 `x509: certificate signed by unknown authority`。
> 指定这个文件就彻底绕过了。
>
> 换机后如果目录里没有它，从 `C:\Program Files\Git\mingw64\etc\ssl\certs\ca-bundle.crt`
> 复制一份过来即可。

### 用完之后

**直接关掉 `生成公网访问地址.cmd` 的窗口就行**，公网地址立刻失效。

顺带一提：浏览器会缓存 Cloudflare 的调试信息，介意的话用无痕窗口访问。

## ⚠️ 公网暴露的安全须知

**比局域网风险高得多，请务必看完**：

| 风险 | 处置 |
|---|---|
| **admin 默认密码挂在公网上 = 不设防** | **必须先改**（见下方第一章），已经是硬性前提 |
| 任何拿到链接的人都能看到登录页 | 只在试用期间开，**不要长期挂着** |
| 审核员的个人信息、企业名会进公网 | 试用完在后台**清理测试数据** |
| 免费隧道无SLA，可能随时不通 | 重要演示别只留这一条路 |

**必须做的两件事**：
1. **改掉 admin 密码**（默认密码写在 `.env` 里，且曾被打印过）
2. **用完就关**

## 第一章 · 改掉 admin 密码（必须做）

**做法**（不用敲命令）：

```
右键 重置管理员密码.cmd → 以管理员身份运行
→ 直接按回车（自动生成随机强密码）
→ 抄下屏幕上显示的密码
→ 重启 打开评估工具.cmd 的窗口生效
```

已完整实测：生成密码 → 写入数据库 → 登录接口验证通过，链路全通。

## 第二章 · 试完之后清理

```powershell
# 1. 关掉 生成公网访问地址.cmd 窗口（公网立刻失效）
# 2. 关掉 打开评估工具.cmd 窗口（服务停止）
# 3. 如果之前放行过本机防火墙，删掉规则
netsh advfirewall firewall delete rule name="GMP Audit Tool 8780"
# 4. 登录后台，把试用期间建的测试项目删掉
```

## 备用方案 A · 局域网（同办公室时更省事）

**这是唯一需要管理员权限的一步**，我（AI）没有权限代你做。

```
右键 打开评估工具.cmd → 以管理员身份运行
```

如果脚本提示防火墙没放行，管理员 PowerShell 跑这一行：

```powershell
netsh advfirewall firewall add rule name="GMP Audit Tool 8780" dir=in action=allow protocol=TCP localport=8780 profile=any
```

然后把 `http://192.168.1.11:8780/` 发给同事。

> ⚠️ **IP 会变**，每次用前`ipconfig` 确认 IPv4。
> ⚠️ **必须用手机连同一 WiFi 打开试一次** —— 自己电脑能开不代表别人能开。
> ⚠️ 对方用**移动数据**（不是同一 WiFi）就访问不了。

### 打不开的排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 手机打不开，电脑能开 | 防火墙没放行 | 跑上面那条 netsh 命令 |
| 提示「已拒绝连接」 | 服务没在跑 | 检查 cmd 窗口还在不在 |
| IP 变了 | 路由器重分配 | `ipconfig` 重查 |
| 页面打得开但登录报错 | 数据库路径不对 | 确认从 `gmp-增值评估工具\` 下启动 |
