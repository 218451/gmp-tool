### ★★ 为什么不能选「入门型」（腾讯云官方文档原文警告）

> 「中国香港入门型套餐**无法保障中国内地与中国香港之间的跨境公网质量**，

「入门型」和「锐驰型」的唯一本质差别就是这个：
**入门型 2核2G = 20Mbps 带宽 + 512G 月流量；锐驰型 2核2G = 200Mbps + 无限流量。**
价格只差 17 元/月（38 vs 55），但跨境质量天差地别。
本工具的用户是**在国内各企业现场**的审核员，全部要跨这个链路 —— **别省这17 元**。

## 一、★ 最容易踩的坑：国内节点要 ICP 备案

这是唯一一个会让「买完第二天就能用」这个预期彻底落空的地方。

**规则**：
- 服务器买在**中国大陆地域**（杭州、上海、北京、广州…）→ 上线对外访问**必须先完成 ICP 备案**
- ICP 备案周期：**7~20 个工作日**，要提交企业营业执照、法人身份证、网站负责人信息，审核期间阿里云会打电话核验
- 备案通过后还要做**公安网安备案**（ICP 备案完成后 30 日内），这个更快但也要提交材料
- **备案期间网站无法通过域名访问**，只能用 IP 直连，且部分省份的服务器会直接封 80/443 端口

**所以**：如果你需要「这周就要让别人打开」，**国内节点直接排除**，只能选香港/新加坡/美西等海外节点。

**海外节点代价**：
- 国内访问延迟 30~80ms（比国内节点的 10~30ms 高，但这个工具是表单类应用，体感差异很小）
- **腾讯云香港分两种套餐，入门型明确不保障跨境质量，必须选锐驰型**（见开头）
- 香港/海外节点**时长折扣只对 2核8G 以上生效**，2核2G 没有折扣，买 1 个月和 12 个月同价
- 节点地域**买定不可改**，只能退款重买，且**退款后新用户资格作废**，同配置价格会从 68 跳到 459 元/年

## 二、配置要买多少（已按实际项目体积核算）

**实测数据**（来自本机 `du -sh`）：

```
server/node_modules    373 MB   ← 后端依赖
web/dist                1.4 MB  ← 前端构建产物
server/prisma/v2.db    1.5 MB   ← 数据库
```

**结论：2 核 2G 起，2 核 4G 更稳。**

理由：
- SQLite 是**单文件嵌入式数据库**，不需要单独装 MySQL/PostgreSQL，省掉一整套数据库运维
- 实际并发很低——审核工具是「几十个审核组按计划推进」，同时在线通常不超过 10~20 人（审核员是分批下现场做评估，不是全天在线）
- 跑 Docker Compose 两个容器（server + nginx），2G 内存跑 `node:22-bookworm-slim` + nginx 绰绰有余
- AI 调用走 DeepSeek API，**模型在云端**，服务器只发 HTTP 请求，不吃算力

**不要选的**：
- ❌ 1 核 1G —— Docker + 构建过程内存紧张，容易 OOM
- ❌ GPU 服务器 / 计算型 c7 —— 完全用不上
- ❌ 按量付费 —— 这种后台常驻服务按量付费反而更贵

## 四、★ 下单前必须确认的四件事

1. **你是不是新用户**
   38/68 元/年 是**首单获客补贴**，不是长期价格。
   老用户续费价：阿里云 2核2G **79 元/年**（其实也不贵，见下）。
   **判断口诀**：不确定自己是不是新用户，就直接买 68 元/年那档，它对新老用户都接近这个价，不会踩坑。

2. **地域选香港还是国内**
   - 选了就不能改，退款重买会**作废新用户资格**
   - 买国内节点前，先确认你有没有备案过的域名主体（企业营业执照）

3. **续费价格**
   阿里云 2核2G 续费 **79 元/年**，这个价格其实是合理的，不必焦虑。
   真正要避开的是「退款重买导致资格作废、同配置跳到 459 元/年」——**所以下单前想清楚地域，别冲动退**。

4. **不要用第三方代购/返利链接下单**
   价格一样，但代购可能用你自己的企业身份下的单，后续备案、发票、实名认证都会出問題。**直接官网注册买**。

## 六、买完之后的部署路线

买香港节点 → 半小时上线，全程命令见 `云服务器部署方案.md`（同目录）：

```bash
# 1. 用 Xshell/WinSCP 或 Git Bash 连上服务器（22 端口，不受代理影响）
# 2. 装 Docker
curl -fsSL https://get.docker.com | bash

# 3. 拉代码（★ 注意走 SSH，HTTPS 被代理）
git clone git@github.com:218451/gmp-tool.git
cd gmp-tool/gmp-增值评估工具

# 4. 关键：v2.db 和 .env 不在 Git 里，要单独补
scp server/prisma/v2.db 服务器:/data/gmp-audit/v2.db
cp server/.env.example server/.env
# 改 .env 里的 DATABASE_URL 指向 /data/gmp-audit/v2.db

# 5. 起服务
docker compose up -d --build
```

**两个必须注意的点**：

1. **`v2.db` 不在 Git 里**（被 `.gitignore` 排除）。如果不手动传，服务器上是空库，审核员注册的账号和已有项目数据全丢。
2. **服务器安全组要放行 8080 端口**（腾讯云/阿里云控制台 → 安全组 → 添加规则 TCP:8080）。
   注意：云端 Docker 模式的访问端口是 **8080**，不是 8780（8780 是本机开发模式的端口）。
   这跟本机 Windows 防火墙是两回事，两个都要开。
